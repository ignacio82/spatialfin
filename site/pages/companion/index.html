SpatialFin Companion Hub

An optional self-hosted Docker service for your home server that adds QR/6-character Quick Connect brokering, private LAN SearXNG web search, and remote client diagnostics.

Completely Optional Server Component (Distinct From Wear OS)

You do not need SpatialFin Companion Hub to connect to Jellyfin, mount SMB/NFS shares, cast over FCast, or watch offline downloads. Companion Hub is also completely separate from SpatialFin for Wear OS (the smartwatch app on Google Play).

What It Does & Optionality

SpatialFin Companion Hub runs alongside Jellyfin via Docker Compose on port 1982. Install it only if you want hands-free QR/pin device onboarding, LAN SearXNG search for Voice AI, or centralized remote log collection.

Prerequisites

  • A Linux/macOS/Windows Docker host (or NAS) with Docker Engine and Docker Compose v2 installed.
  • Reachable LAN IP or Tailscale hostname on TCP port 1982 from your Android XR headset, TV, phone, or WebXR browser.

Quick-Start Deployment (Verified Against Upstream master)

  1. Clone the upstream repository and start the stack using docker-compose.yaml (including the bundled SearXNG sidecar): 
    git clone https://github.com/ignacio82/SpatialFin-Companion.git
cd SpatialFin-Companion
docker compose up -d --build
  2. Verify the health endpoint responds cleanly on port 1982: 
    curl -fsS http://127.0.0.1:1982/healthz
  3. Open http://<server-ip>:1982 in a browser to complete first-time admin login using the printed bootstrapPin or an explicit COMPANION_ADMIN_PASSWORD environment variable.

Bundled Services & Environment Controls

Setting / Endpoint Purpose
GET /healthz Container health check on port 1982.
GET /api/v1/search / COMPANION_SEARXNG_URL Queries the bundled private SearXNG sidecar for local search lookups.
COMPANION_ADMIN_PASSWORD / bootstrapPin Protects the Companion Hub admin web dashboard on first startup.
COMPANION_AUTO_UPDATE=false Opt out of background self-update checks for pinned/air-gapped deployments.

QR & 6-Character Quick Connect Pairing

  1. Open Companion Hub in your browser and select Pair Device to display a QR code and short 6-character pairing code.
  2. Inside SpatialFin (headset, TV, or phone) or WebXR, scan the QR code or enter the code from onboarding—Companion Hub exchanges your configured Jellyfin session cleanly without typing server URLs or passwords inside the headset.
Technical protocol notes (qc_broker_v1 & X-Setup-Token)

Companion Hub QR payloads use the versioned qc_broker_v1 JSON schema carrying the broker base URL, short-lived Quick Connect secret, and scoped header token (X-Setup-Token) so devices verify authenticity without exposing admin credentials.

Remote Log Viewer & Security Boundary

  • Remote Support Logs: When troubleshooting a headset crash or codec quirk, send a diagnostic snapshot from SpatialFin Settings to inspect it directly inside the Companion Hub web UI.
  • Local App Lock Isolation: Companion Hub never receives your Biometric/PIN App Lock secrets or AES-256-CTR offline encryption keys—those stay locked strictly on each Android device.

Verify It Works

  • Confirm http://<server-ip>:1982/healthz returns HTTP 200.
  • Scan a test pairing QR from SpatialFin and confirm your Jellyfin server profile populates automatically.

Troubleshooting

  • Full server administration reference: For reverse-proxy templates, environment flags, and container upgrades, consult the upstream SpatialFin-Companion repository.
  • QR pairing rejected: Confirm your headset/phone clock is accurate and generate a fresh pairing code (tokens expire promptly after generation).
