SpatialFin QuickJS & Grayjay Plugin Guide

Build lightweight JavaScript source plugins or adapt Grayjay plugins to run directly inside SpatialFin's sandboxed QuickJS engine on Android XR, Phones, and Android TV.

Security Warning: Unverified Third-Party Scripts

SpatialFin does not enforce cryptographic scriptSignature verification on installed plugins yet. While runtime HTTP calls inside the QuickJS VM are restricted by UrlTargetPolicy.PUBLIC_INTERNET_ONLY, manual manifest/script URLs or QR codes entered under Sources → Plugins → Install Plugin can still download from LAN HTTP endpoints and execute arbitrary plugin logic within the sandbox. Only install scripts you wrote or audited yourself.

Runtime Architecture & Resource Caps

SpatialFin executes plugins natively inside Android using quickjs-kt (see PluginEngine.kt and PluginClient.kt in the :plugins module) without WebViews or background Node runtimes:

  • Fresh VM per call: Every home feed, search, or stream resolution call creates an isolated QuickJS runtime and disposes it when finished—do not rely on in-memory globals persisting across separate UI actions.
  • Synchronous execution only: http.GET(url, headers) and http.POST(...) execute synchronously and return { isOk, code, body, headers }. async/await, Promises across I/O boundaries, and browser fetch() are not supported.
  • Hard resource limits: 20.1 s (20,100 ms) HTTP execution timeout, 2 MiB script download cap during install, and 4 MiB HTTP response body cap in RealHttpBridge.
  • Install Path: Install via Sources → Plugins → Install Plugin (paste a manifest JSON URL or scan a QR code) and update later using the same source settings panel.

Grayjay API Compatibility Matrix

SpatialFin implements Grayjay's core source contract alongside explicit sandbox guards verified in :plugins unit tests:

Surface / API SpatialFin Behavior Source Reference
source.enable(config, settings, '') Called before each call with configured PluginSetting map and empty savedState string (source.saveState() is not called). PluginClient.kt
http.GET / http.POST (usePlatformAuth = false) Synchronous GET/POST only; auth/cookies from platform web sessions are disabled. RealHttpBridge.kt
UrlTargetPolicy.PUBLIC_INTERNET_ONLY Blocks loopback (127.0.0.1), link-local, and RFC 1918 LAN targets inside script HTTP calls to mitigate SSRF. RealHttpBridge.kt
bridge.isLoggedIn / getSettings / setSettings Stubbed / read-only helpers; configure credentials or API keys via manifest PluginSetting inputs instead of runtime setSettings writes. PluginEngine.kt
new PlatformAuthorLink({ id, name, url }) Expects a single options object (passing positional arguments drops author.name). PluginEngine.kt
source.resolveVideoUrl(videoUrl) Must return an object whose url resolves to the playable media stream strictly distinct from the input page videoUrl. PluginContentRepository.kt
scriptSignature Not enforced: unsigned or third-party scripts load without signature rejection. PluginModels.kt

SpatialFin Manifest Extensions (PluginConfig)

Beyond standard Grayjay fields (id, name, author, description, version, scriptUrl, capabilities, settings), PluginModels.kt supports spatial metadata extensions:

  • homeRows / homeRowTemplates: Custom category rails on the plugin Home tab.
  • presentation: "verticalVideoFeed": Enables vertical short-form swipe feeding when appropriate.
  • projection & stereoMode: Annotate VR180 / 360° or SBS/TAB stereoscopic feeds directly from plugin metadata.
  • isLive: Flags live streams in card badges and player UI.

Verify It Works

  1. Host manifest.json and script.js at HTTPS URLs with scriptUrl pointing to your script.js.
  2. Open SpatialFin and navigate to Sources → Plugins → Install Plugin, paste the manifest URL (or scan a QR code), and open Settings on the installed plugin to configure instanceUrl.
  3. Open the plugin from Sources and verify Home rows, Search results, and video stream resolution play natively.

Troubleshooting & Further Reading

  • author.name renders blank or missing: Ensure you pass an object literal new PlatformAuthorLink({ id, name, url }) rather than positional arguments.
  • Stream resolution error even when URL exists: Ensure source.resolveVideoUrl(videoUrl) returns a direct stream URL strictly distinct from the page URL passed in.
  • Local/LAN API test blocked inside script: UrlTargetPolicy.PUBLIC_INTERNET_ONLY rejects private IP ranges at runtime; test against a public HTTPS endpoint (or a Robolectric + MockWebServer unit test).
  • Upstream Grayjay resources: Browse existing scripts on Grayjay Plugin Hub and read the Grayjay Plugin Development Guide.

In-App QuickJS Plugins vs. FCast External Casting

QuickJS plugins run inside SpatialFin to browse and resolve online video sources natively. Sending playback between devices (XR, TV, Watch, WebXR) uses the external FCast casting protocol—documented separately in the Casting & Split-A/V Guide.
