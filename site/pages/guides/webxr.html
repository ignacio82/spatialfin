SpatialFin WebXR Guide (/web/)

Run SpatialFin directly inside headset and desktop browsers at https://spatialfin.martinez.fyi/web/ using Three.js WebXR cinema, SubtitleOctopus ASS/SSA rendering, and optional Tailscale Serve HTTPS access.

What It Does & Optionality

SpatialFin WebXR requires zero APK installation and operates independently of the native Android apps. Use it on Meta Quest Browser, Galaxy XR Browser, desktop Chromium, or as an installable Progressive Web App (PWA) alongside Companion Hub or direct Jellyfin CORS connections.

Prerequisites

  • A WebXR-capable Chromium browser (Chrome 142+ on Android XR/desktop or Quest Browser).
  • A Jellyfin server configured with CORS headers allowing https://spatialfin.martinez.fyi (or served over HTTPS via Tailscale Serve / reverse proxy).

Step-by-Step Setup

1. Configure Jellyfin CORS Headers

  1. Open your Jellyfin Web Dashboard as an administrator.
  2. Go to Dashboard → Networking and scroll to Known Proxies / CORS (or your reverse-proxy CORS configuration).
  3. Add https://spatialfin.martinez.fyi to allowed origins so the browser permits authenticated API and stream requests.

2. Handle Chrome 142+ Local Network Access

Modern Chromium browsers gate HTTPS origins from reaching private 192.168.x.x / 10.x.x.x addresses unless permitted:

  • When opening /web/ and connecting to a LAN Jellyfin or Companion Hub IP, accept the browser's Local network access permission prompt.
  • If mixed-content rules block plain http:// LAN requests from an https:// origin, expose Jellyfin over HTTPS using Tailscale Serve or a local TLS reverse proxy.

3. Tailscale Serve HTTPS & Companion wss:// Receiver

  • Run tailscale serve in front of your Jellyfin or Companion Hub instance to obtain a valid trusted https://*.ts.net certificate without exposing ports to the public internet.
  • To use /web/ as an FCast / Split-A/V WebSocket receiver when hosted over HTTPS, point it at a TLS-secured WebSocket (wss://) endpoint rather than unencrypted ws://.

Verify It Works

  • Visit https://spatialfin.martinez.fyi/web/, sign in via Companion Hub or Manual Connect, and confirm posters load without CORS errors in browser DevTools.
  • Enter VR/XR cinema mode and confirm the floating virtual screen renders smoothly with audio.

Troubleshooting

  • Login fails with network/CORS error: Verify https://spatialfin.martinez.fyi matches exactly (no trailing slash) in Jellyfin networking settings or your reverse proxy's Access-Control-Allow-Origin response header.
  • Browser refuses http://192.168... from https://: Approve Local Network Access in Chrome site permissions or switch your server URL to a https://*.ts.net Tailscale Serve endpoint.
