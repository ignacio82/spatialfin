Theater Audio (spatialfin-avr)

Pair Galaxy XR, Android Phone/Beam, Android TV, or WebXR (/web/) with the optional self-hosted spatialfin-avr Rust daemon to play synchronized multi-room 24-bit/48 kHz surround and TrueHD Atmos audio over physical speakers while keeping HDR/3D video locked at 1.0000×.

Optional Self-Hosted Audio Daemon (Separate From Companion Hub)

You do not need spatialfin-avr for local playback, headphone audio, or standard FCast/Google Cast streaming. spatialfin-avr is an independent open-source Docker service dedicated to Split-A/V physical speaker theaters and is separate from SpatialFin Companion Hub.

What It Does & Optionality

spatialfin-avr fetches your movie's lossless audio track directly from Jellyfin while SpatialFin renders video on your headset, phone, TV, or browser. Because the AVR absorbs clock drift silently in DSP, video stays locked at native 1.0000× cadence with zero dropped or repeated frames:

  • Multi-Room Persistence & Embedded Web UI: Host multiple independent rooms (for example, a bedroom 2.0 SendSpin pair, a living room HDMI soundbar, and a family room 7.1 array) on one server. Per-room volume, mute, EQ bypass, upmix mode, and LR4 crossover edits persist automatically across container restarts and sync across every paired client. Manage everything from any browser at http://<avr-host>:1986/.
  • TrueHD Atmos OAMD 3D VBAP & Live Upmix: Decodes TrueHD Atmos Object Audio Metadata (oamd) via 3D VBAP with live object-count / bed-fallback telemetry in the player HUD (< 200 ms automatic bed failover), delay-invariant EQ Bypass, and four live upmix modes (Native, All-Channel Stereo, DTS Height Upmix, Neural Height).
  • In-Player Multi-Room Quick Switcher: Switch active playback between any paired room or back to local device audio in two taps without restarting playback or losing XR screen placement.

Quick-Start Docker Deployment

  1. Clone ignacio82/spatialfin-avr and launch the multi-arch (amd64 / arm64) container: 
    git clone https://github.com/ignacio82/spatialfin-avr.git
cd spatialfin-avr
docker compose up -d --build
  2. Confirm the container passes its built-in healthcheck: 
    docker exec spatialfin-avr spatialfin-avr healthcheck
  3. Open http://<server-ip>:1986/ in any browser to configure rooms, drag-and-drop speaker positions on the 2D SVG floorplan, pair devices via inline SVG QR code, revoke old clients, or configure Music Assistant handoff.

Key Environment Variables (TLS, CORS & Handoff)

Variable Purpose
SPATIALFIN_AVR_PORT / SPATIALFIN_AVR_ADVERTISED_HOST Control-plane HTTP port (1986 in Compose) and pinned LAN IP for mDNS and pairing QR codes.
SPATIALFIN_AVR_USE_TLS=true Enables built-in HTTPS/WSS. Uses user PEM certs when set, or auto-generates a persistent 10-year ECDSA P-256 self-signed cert under /data/tls/ with stable SPKI pinning across IP changes.
SPATIALFIN_AVR_TLS_CERT / SPATIALFIN_AVR_TLS_KEY Optional CA-backed PEM certificate and key (required for browser-trusted WebXR HTTPS connections); hot-reloaded on SIGHUP or file update.
SPATIALFIN_AVR_TLS_PORT / SPATIALFIN_AVR_DISABLE_HTTP Run dual HTTP + HTTPS ports concurrently, or enforce HTTPS-only mode (healthcheck and pair-pin CLI commands work automatically over HTTPS).
SPATIALFIN_AVR_CORS_ORIGINS Strict comma-separated browser origin allowlist (for example, https://spatialfin.martinez.fyi) with automatic Chromium Private Network Access (PNA) preflight headers and CSWSH Origin checks.
SPATIALFIN_AVR_MA_URL / SPATIALFIN_AVR_MA_TOKEN Optional Music Assistant handoff (also configurable write-only in the Web UI Server Settings tab) to pause active Music Assistant players before cinema playback claims a speaker.

Pairing & Playback Across Devices

Android XR & Phone / Beam Pro

  1. Open the Cast sheet in SpatialFin—nearby servers appear automatically via _spatialfin-avr._tcp.local. mDNS, or tap Pair Theater AVR to scan the Web UI's inline SVG QR code or enter host:port and a single-use 120 s 6-digit PIN.
  2. One Android Keystore token is shared across all rooms on that server. When TLS is enabled, scanning the QR code automatically pins the server's leaf SPKI fingerprint with sticky anti-downgrade protection.
  3. During playback, use the Theater HUD strip to switch rooms in two taps, adjust master volume, toggle EQ Bypass, cycle all four upmix modes, inspect live Atmos/OAMD object counts, or fold back to headset/device audio.

Android TV

  1. Select the D-pad Theater Audio pill in the top bar (or Theater Audio & Output in the overflow menu) to pick a discovered room or pair manually by host:port and 6-digit PIN.
  2. When pairing against a self-signed TLS AVR on Android TV, confirm the 8-character TLS SAS code shown in the AVR Web UI / CLI before saving the pin.
  3. During playback, Android TV gates audio launch until HDMI display refresh-rate switching settles (≤ 2.5 s), intercepts remote Volume + / − / Mute keys to control the AVR directly, and exposes a D-pad Theater HUD and room switcher.

SpatialFin WebXR (/web/)

  1. Configure spatialfin-avr with a browser-trusted TLS certificate (or Tailscale Serve) and set SPATIALFIN_AVR_CORS_ORIGINS=https://spatialfin.martinez.fyi.
  2. Open the Cast dialog inside SpatialFin WebXR, enter your AVR host/port and 6-digit PIN (or Bearer token), and choose a room.
  3. Both 2D browser and 3D WebXR cinema authenticate WebSockets via single-use tickets (POST /api/v1/ws/ticket) and drive lip-sync from requestVideoFrameCallback timing beacons. See the WebXR Guide for browser permission details.

Audio Outputs & Unified ESP32-C5/S3 Firmware

Each room can mix any combination of the three supported output backends, protected across rooms by a conflict registry (409 speaker_busy):

Output Backend Best For Key Capabilities
LAN SendSpin WebSocket (_sendspin._tcp) Solder-free multi-room smart speakers mDNS discovery, per-speaker identification chimes, automatic mono/stereo downmix & hardware delay alignment.
Direct Host PC HDMI / ALSA Soundbars, AV receivers & USB DACs on the Docker host 2.0–7.1 uncompressed PCM over /dev/snd with startup-cached format/channel probing and 2-ch ARC warnings.
Noise KKpsk2 TCP (:8937) — Linux & ESP32-C5/S3 Clock-locked multi-channel front stages & custom Wi-Fi 6 speakers Includes Linux spatialfin-sink (2–8 ch) and unified ESP-IDF v5.3+ firmware for ESP32-C5 / ESP32-S3 supporting i2s_std_2ch (stereo) and i2s_tdm_8ch (8-ch TDM with ≥ 2 MB PSRAM) over compact lossless FLAC framing (bin_flac), fixed-point 2D Kalman + Hermite ASRC, and 5 ms ramped flush.

Full GPIO pinout tables, DAC wiring notes (PCM5102A, CS42448, PCM1681), and ESP-IDF build commands live in spatialfin-avr/hardware/README.md.

Room & Lip-Sync Calibration

  • Acoustic Lip-Sync Auto-Calibration: From the in-app Room Calibration screen on Android XR or Phone/Beam, tap Auto-Calibrate Lip-Sync at your listening position. SpatialFin plays five timed chirp bursts through your speakers (with a 1.5 s HDMI wake lead-in), subtracts acoustic time-of-flight, checks SNR/IQR quality, offers a flash-and-chirp preview with ±5 ms trim nudges, and persists the measured fixed_hw_delay_us.
  • 2D SVG Floorplan & Speaker Trim: Drag speakers on the Web UI's top-down SVG floorplan (All / Floor / Height filter) with live Euclidean delay preview and conflict-safe If-Match saves.
  • REW / CamillaDSP & UMIK-1 Sweeps: Import REW/CamillaDSP Room EQ bundles in-app or via the Web UI, or connect a USB-C OTG UMIK-1 microphone to Beam/Phone to run automated Farina sine-sweep room EQ calibration.
  • Galaxy XR 6DoF LCR Screen Lock: Pin a front-wall ARCore anchor on Galaxy XR so your virtual screen aligns physically with your left, center, and right speakers, including a dark-room Play Center Chime / Lock Here fallback.

Verify It Works

  • Open http://<avr-host>:1986/ and confirm the Web UI loads with your rooms and discovered outputs.
  • Play a movie in SpatialFin with a room selected, verify the Theater HUD shows live codec/Atmos telemetry, and test switching rooms or muting without interrupting video.

Troubleshooting

  • TLS pin mismatch banner after server rebuild: Re-pair by scanning a fresh Web UI QR code (or confirming the new 8-character SAS on TV). Keeping /data/tls/key.pem mounted preserves your SPKI pin across IP changes and container updates.
  • WebXR refuses connection from https://spatialfin.martinez.fyi/web/: Browsers reject plain http:// and self-signed LAN certificates from HTTPS origins. Mount a CA-backed cert (SPATIALFIN_AVR_TLS_CERT/KEY or Tailscale Serve) and include https://spatialfin.martinez.fyi in SPATIALFIN_AVR_CORS_ORIGINS.
  • HDMI output shows 2-channel ARC capability warning: Confirm your TV/AVR eARC or passthrough path accepts multi-channel LPCM, or switch to a direct AVR HDMI input.
  • 409 speaker_busy when starting playback: Another active room currently holds that physical speaker or ALSA output; stop the other room or assign disjoint outputs per room.
