Getting Started With SpatialFin

SpatialFin works with an existing Jellyfin server or without any server at all. Pick the onboarding flow that fits your network and devices.

What It Does & Optionality

On first launch, SpatialFin presents three independent source paths on Android XR, Android Phone (including Beam Pro), and Android TV:

  • Connect a Jellyfin Server: Stream your Jellyfin 10.10+ libraries, use SyncPlay rooms, and download encrypted offline copies.
  • Add Network Shares (SMB / NFS): Browse Windows/macOS shares or NAS exports directly with optional TMDB metadata enrichment—no Jellyfin server needed.
  • Play Local Storage or Plugins: Index media stored under device folders, trigger playback via system Open with intents, or install sandboxed QuickJS plugins.

Prerequisites

  • SpatialFin v{{version}} installed from Google Play or GitHub Releases (Android API {{minSdk}}+).
  • For Jellyfin mode: a reachable Jellyfin http:// or https:// URL (LAN IP, Tailscale IP, or domain) and user credentials or Quick Connect enabled on your server.
  • For Android LAN keyboardless setup (XR headsets & TVs): another device (phone or laptop) on the same Wi-Fi/LAN subnet.

Step-by-Step Setup

Option 1: Quick Connect or Credentials

  1. Choose Connect to Jellyfin on the welcome screen and enter your server URL (or pick a discovered local server).
  2. Tap Quick Connect to generate a 6-digit code formatted like 123 456.
  3. In a browser or existing Jellyfin admin session, open Dashboard → Users (or user profile Quick Connect) and authorize the displayed code.
  4. SpatialFin signs in immediately and loads your media libraries.

Option 2: Android LAN Web Wizard (Port 41230)

Typing long server URLs, Tailscale hostnames, or SMB credentials inside a headset or TV remote can be tedious. SpatialFin runs a built-in temporary local HTTP server on Android XR, TV, and phones for phone-assisted setup:

  1. On your headset or Android TV, select Set up from another device (LAN) on the onboarding screen.
  2. Note the local setup URL shown on screen (for example, http://192.168.x.x:41230/setup) and the short pairing code (formatted like K7P-9M2).
  3. Open that URL on your phone or laptop on the same LAN, enter the pairing code, and paste your Jellyfin URL, credentials, or SMB/NFS settings.
  4. Submit the form; the Android client applies the configuration immediately and closes the temporary setup listener.

Option 3: Server-Free Local Files, SMB/NFS & Plugins

  1. Choose Browse Local Media or open Sources after skipping server setup.
  2. Add device folders, mount an SMB or NFS share (with optional TMDB lookup for posters and overviews), or install a source manifest under Sources → Plugins → Install Plugin.
  3. To play an external file or stream URL from Android Files or another app, pick SpatialFin from the Android Open with chooser.

Verify It Works

  • Your selected Jellyfin server, local folders, or SMB/NFS libraries appear in the navigation rail/bottom bar.
  • Starting a video opens the native player for your device form factor (XrPlayerActivity, BeamPlayerActivity, or TvPlayerActivity).

Troubleshooting

  • Phone cannot reach :41230/setup: Confirm both devices are on the same LAN without AP/client isolation enabled on your Wi-Fi router, and check you entered the current pairing code (K7P-9M2 format) before it expires.
  • Quick Connect button missing: Ask your Jellyfin administrator to enable Allow Quick Connect in Jellyfin Server Dashboard → General.
  • Multi-version movies or episodes: If a Jellyfin library entry has multiple encoded files, use the version chip selector on the item detail screen before tapping Play.
